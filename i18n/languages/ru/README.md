## Подготовительная работа

* Один зарубежный сервер, имеющий публичный IP
* Установка протокола Reality: необходимо подготовить целевой домен, соответствующий требованиям Xray.
* Установка версии TLS: необходимо подготовить доменное имя и правильно настроить записи A и/или AAAA в соответствии с доступной сетью сервера; в двустековой среде рекомендуется одновременно настроить корректные записи A и AAAA. Скрипт поддерживает автоматическое определение сетевой возможности IPv4/IPv6; при наличии двустековой связи он может одновременно сформировать соответствующие точки входа для клиентов.
* Чтение[Xray Официальная документация](https://xtls.github.io)Ознакомьтесь с понятиями, связанными с Reality, TLS, WebSocket, gRPC и Xray.
* **Убедитесь, что установлен curl**: пользователь CentOS выполняет`yum install -y curl`Пользователь выполняет Debian/Ubuntu`apt install -y curl`

## Режим установки

| Режим | Описание |
|------|------|
| Reality + Nginx | Рекомендуемый режим позволяет по необходимости добавлять простой протокол ws/gRPC/xHTTP для балансировки нагрузки. |
| Nginx + TLS | Поддерживает ws/gRPC/xHTTP и автоматически подает заявку на получение и продлевает сертификаты Let's Encrypt |
| ws/gRPC/xHTTP ONLY | Режим независимого входящего соединения без TLS, в основном используется для бэкенд-систем или сценариев балансировки нагрузки. |
| Узел пересадки | Роль отдельного сервера, использующего только Nginx Stream для перенаправления на один целевой объект TCP, без установки Xray. |
| Docker | В образе предустановлены Xray, Nginx и основной скрипт. |

При установке соответствующих моделей для ws/gRPC/xHTTP можно выбрать.`ws`、`gRPC`、`xHTTP`Или`ws+gRPC+xHTTP`Скрипт сгенерирует соответствующие порт, путь, ссылку для обмена и QR‑код; в настоящее время Clash не поддерживает xHTTP, о чём скрипт уведомит в выводе конфигурации.

## Инструкция по перенастройке

При повторном запуске установки в уже установленной среде скрипт автоматически создаст резервную копию текущей конфигурации и предложит три варианта перенастройки:

| Путь | Описание | Ограничение |
|------|------|------|
| Сохранить конфигурацию и повторно развернуть | Сохранить пользовательские настройки routing/outbounds/DNS и многопользовательскую конфигурацию, изменяя только поля, выбранные пользователем (порт, путь, параметры UUID, Reality и т. д.). | Не поддерживается перенос изменений структуры (например, ws → gRPC); для изменения набора передаваемых объектов необходимо воссоздать его с использованием стандартного шаблона. |
| Стандартная шаблонная реконструкция | Создайте стандартную конфигурацию шаблона, используя текущие повторно используемые параметры; пользовательский routing/outbounds/DNS может быть удалён. | Не требуется обязательное сохранение числа пользователей. |
| Переключение режима | Переключение на другой протокольный режим (например, Reality → TLS) по умолчанию предусматривает повторное использование только основного пользователя UUID/email. | Другие пользователи не будут перенесены автоматически; перед переключением будет выведено соответствующее уведомление. |

При сбое на любом этапе перенастройки (запись конфигурации, запуск сервиса, проверка работоспособности и т. д.) происходит автоматический откат к резервной исходной конфигурации. Директория резервных копий использует уникальный временной штамп, что позволяет выполнять последовательные многократные перенастройки без возникновения конфликтов.

## RillML Xray AI Помощник по эксплуатации и обслуживанию

RillML (сокращённо Rill) предоставляет Xray возможности локальной адаптивной интеллектуальной эксплуатации и обслуживания.

Встроен помощник по эксплуатации и обслуживанию AI, который в режиме реального времени отслеживает состояние Xray/Nginx, автоматически диагностирует неисправности и предлагает рекомендации по их устранению, без необходимости использования внешнего API. В главном меню введите:`9`Или выполнить`idleleo --rill-agent`Войти.

**Ключевые компетенции**

* Мониторинг: в режиме реального времени отслеживаются состояние сервиса Xray/Nginx и его конфигурации.
* Диагностика: определение первопричины неисправности с указанием уровня достоверности (высокий / средний / низкий / недостаточно доказательств)
* Определение: автоматическое определение типа неисправности и предоставление рекомендаций по её устранению; в описании чётко указывается, допускается ли автоматическое устранение или предоставляются только рекомендации.
* Режим: интеллектуальное определение / только наблюдение / безопасное отключение; до активации автоматического изменения система не будет изменена.

**Часто используемые команды**

| Операция | Команда |
|------|------|
| Открыть меню инструмента обслуживания AI | `idleleo --rill-agent` |
| Установить или восстановить движок проверки AI | `idleleo --rill-agent-install` |
| Просмотреть состояние проверки AI | `idleleo --rill-agent-status` |
| Запуск диагностики неисправностей AI | `idleleo --rill-agent-diagnose` |
| Проверка движка утверждений AI | `idleleo --rill-agent-verify` |
| Безопасное отключение AI проверка | `idleleo --rill-agent-safe-disable` |
| Удалить движок Rill AI | `idleleo --rill-agent-uninstall` |

Двигатель принятия решений на основе AI в настоящее время находится на стадии тестирования; рекомендуется ориентироваться преимущественно на диагностические рекомендации, по умолчанию система не будет изменяться автоматически.

## Развертывание AI Skill

Поддерживается автоматическое развертывание Xray с помощью инструмента AI (например, Trae), без необходимости ручного взаимодействия. Подробности см. в[Xray_bash_onekey_skill](https://github.com/hello-yunshu/Xray_bash_onekey_skill)。

В традиционном способе необходимо SSH на сервер, запустить скрипт установки и поочередно отвечать на интерактивные вопросы; в режиме Skill достаточно лишь сообщить AI о своих требованиях, после чего AI автоматически сгенерирует безинтерактивный скрипт и выполнит его, сразу предоставив ссылку на VLESS.

**Режим поддержки**: Reality / TLS / ws ONLY / Переходный узел

**Способ использования**: в инструменте с поддержкой Skill просто скажите «Помоги мне установить Xray на сервер», и AI автоматически соберёт информацию, сгенерирует скрипт, выполнит развертывание и вернёт данные для подключения.

* Если вы не понимаете значения настроек, кроме обязательных полей используйте значения по умолчанию (достаточно нажимать Enter на протяжении всего процесса).

* Не используйте данный скрипт в продакшен-среде до проверки его работоспособности.

* Xray — это отличный открытый инструмент для работы с сетевыми прокси, поддерживающий все платформы, включая Windows, macOS, Android, iOS и Linux.
* Этот скрипт является скриптом для полной настройки одним нажатием; после успешного завершения всех этапов можно настроить клиент в соответствии с выведенными результатами и приступить к использованию.
* **Настоятельно рекомендуется** полностью разобраться в порядке работы и принципах функционирования программы.
